Each tutorial builds one small program from scratch. Code blocks with a
**Run** button open in the [playground](/play/), where you can edit them
and run them again. The playground runs the real Fola interpreter, compiled
to WebAssembly, so you don't need to install anything for the first two
tutorials.

| Tutorial | You'll learn | Runs in |
|---|---|---|
| [1. Word frequencies](/tutorials/word-frequencies/) | Strings, arrays, hashes, blocks, methods | Browser |
| [2. A bank account](/tutorials/bank-account/) | Classes, modules, exceptions | Browser |
| [3. A to-do list CLI](/tutorials/todo-cli/) | `Fola::CLI`, files, JSON | Your terminal |
| [4. A web app](/tutorials/web-app/) | `Fola::Web` routes, templates, testing, serving | Browser, then terminal |

Each tutorial assumes you've read the one before it, or the
[tour](/learn/tour/). For tutorials 3 and 4, [install Fola](/learn/) first.
